# Prueba-Diagnostica

Del Estudiante: Miguel Barrios

Este repositorio contiene las soluciones programadas en C++ para la prueba diagnóstica de **Lenguajes y Compiladores** de la Universidad Nacional Experimental de Guayana (UNEG).

## 📋 Contenido del Proyecto
El proyecto está estructurado en tres carpetas principales, cada una con su respectivo código fuente:

1.  **Problema 1:** Analizador léxico que clasifica componentes de expresiones aritméticas (Números, Operadores, Operandos y Paréntesis).
2.  **Problema 2:** Validador de notación de ajedrez FEN (Forsyth-Edwards Notation) con visualizador de tablero en consola.
3.  **Problema 3:** Verificador de la Conjetura de Collatz dentro de un intervalo [p, q], validando la regla obligatoria q ≥ 100p.

## 🚀 Instrucciones de Compilación y Ejecución
Para ejecutar estos programas en cualquier computadora con un compilador de C++ o ejecutando los archivos .exe.
